# OpenWorld 3D Game

An open-source 3D open-world game built with Three.js. Explore a large procedurally generated world with terrain, trees, buildings, day/night cycle, and a drivable character controller — all in the browser, no build step required.

## Features
- Large open world with procedural terrain, roads, trees and buildings
- Third-person character movement (WASD + mouse), sprint and jump
- Day/night cycle with dynamic lighting and fog
- Minimap, collision with buildings/trees, collectible items
- Runs in any modern browser

## Play
Open `index.html` in a browser, or serve locally:
```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Tech
Three.js (WebGL), vanilla JavaScript, MIT License.
